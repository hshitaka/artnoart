# Fonction de kb-mix

kb-mix répond à : **comment ça s’écoute, comment c’est balancé.**

## Ce qu’il est

- Bus, chaîne, extraits de set.
- Relie la prod au set : `prod → mix → set`.

## Ce qu’il n’est pas

- Pas la prod (la pièce).
- Pas le set (le geste de jouer).
- Pas kb-perf.
