# Outils (pas des KB)

Les outils ne sont pas des knowledge bases. Ils apparaissent sur la carte quand un geste les a déjà servis.

| Outil | Geste tenu | Pas ça |
| --- | --- | --- |
| djay | Set DJ, mashup live | Pas Ableton |
| Ableton | Mashup studio, pièces, ateliers | Pas djay |
| Push | Avec Ableton (atelier, session) | Pas un KB |
| MaxMSP / Bionic Looper | Spectacle vivant déjà joué | Pas un hub |

Le mashup n’est pas un outil. C’est le geste du losange.
