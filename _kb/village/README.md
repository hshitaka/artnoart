# Village

Le village, ce n’est pas un hub. C’est l’inventaire : **kb** (savoir) et **dd** (livraison), plus le bureau.

Règle des liens : [_kb/liens/REGLE.md](../liens/REGLE.md). Une fiche n’est pas un lien. Un lien, seulement s’il a déjà servi.

## Pile

```
bo-ia          →  bureau (qui parle à qui)
  kb-liens     →  relations déjà servies
    kb-perf    →  corps + psy → flow
    kb (métiers)
    dd (outils de livraison)
```
