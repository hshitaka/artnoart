# Fiche — dd-artnoart

**Question :** comment l’atelier se montre : écouter, télécharger.
**Rang :** dd · village
**Où :** ce repo (`hshitaka/artnoart`)

## C’est

- Le site public ARTNOART.
- Extraits prod / mix, dossier presse.
- Deux voies de téléchargement : Direct et Fetch (DWET).

## C’est pas

- Pas le canon DJ (kb-dj).
- Pas a2dd (la livraison des vrais titres).
- Pas djay. Les WAV du site sont des jingles techniques, pas un set.

## Déjà servi

- Prod → Mix publiés ensemble.
- Mix → set : extrait *Live Set Excerpt*.
- Dossier presse : Bionic Looper, ateliers Ableton.
