# Fiche — dd-genre-formater

**Question :** comment un vieux genre de fichier devient le genre canon.
**Rang :** dd · village
**Où :** `hshitaka/genre-formater` (et refonte `genre-formater-refactored`)

## C’est

- Un outil de formatage de genres musicaux.
- Il sert le **Formatage** du pipeline a2dd, pas le live.

## C’est pas

- Pas kb-dj (qui *tient* le canon une fois formaté).
- Pas djay.
- Pas un hub.

## Déjà servi

- Repo public, rôle nommé : convertir d’anciens formats de genres vers un format standardisé.
- Dans a2dd, l’onglet Formatage est le voisin naturel.

## Voir

Le canon après coup : [kb-dj](../dj/FONCTION.md). La livraison : [dd-a2dd](dd-a2dd.md).
