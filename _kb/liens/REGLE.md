# Règle de kb-liens

Une seule règle.

**Un lien n’existe que s’il a déjà servi.**

Servi, c’est un geste réel : un set, un plat, un cours, une session, une date, un flow, une transmission déjà faite.

Ce n’est pas « on pourrait ».
Ce n’est pas une ressemblance.
Ce n’est pas un schéma.

## Comment écrire un lien

Trois champs, rien d’autre :

1. **De → vers** — deux nœuds, pas une liste.
2. **Geste** — ce qui s’est déjà passé, en une phrase.
3. **Statut** — `tenu` ou rien. S’il n’est pas tenu, le lien n’est pas écrit.

Un **losange** (ou une autre figure) est encore un seul geste, avec plusieurs coins. On ne le découpe pas en « on pourrait » de proche en proche. Si le geste n’a pas tenu les quatre coins, ce n’est pas un losange.

## Quand tu hésites

N’écris pas le lien.

Le contenu reste dans son KB métier, tout seul. La carte ne le relie pas.

## Ce que kb-liens n’est pas

- Pas un catalogue.
- Pas un tiroir « artistique ».
- Pas kb-perf. Le flow (corps + psy) ne se range pas ici.
- Pas bo-ia. Les agents et les règles de bureau ne se rangent pas ici.

## Perf

La perf n’est pas un genre musical.

kb-perf est le même KB pour un set, un service culinaire, un cours, une préparation d’herbes : **corps + psy → flow**.

Dans kb-liens, on peut noter qu’un geste **a invoqué** kb-perf. On ne met pas kb-perf au-dessus de la musique, ni dedans.
